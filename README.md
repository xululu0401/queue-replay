# 排队回放台 · queue-replay
一份同日到达/服务记录，按单队列先到先服务回放。1–120人、1–12台，显示等待、等候峰值、全部完成时间及逐人时间轴，枚举台数寻找目标内首个达标配置。

用 node build.cjs 生成单文件 index.html；node --test tests/core.test.cjs 运行测试。纯前端，无外部脚本/CDN/后端；本机手动保存、JSON备份往返、CSV/MD全量清单，PNG含前20人且显式标注。

到达先排序，同刻原行号优先；选择最早可用台，可用时刻相同选最低号。所有台同时开台且连续工作，开台前等待计入，不含休息/离队/插队/技能差异。结束跨日标+N日。只回放输入，不预测客流、不用于医疗分诊。

6组核心测试，400个独立逐分钟现场派工对照。对照比较每人开始/结束/等待及排队峰值，不强求先前闲置时刻不同的两个台获得相同台号。UI实际导出、保存恢复及手机极限证据位于批次上层evidence。
